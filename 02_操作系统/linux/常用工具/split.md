### Linux 文件拆分与合并指南

在 Linux 系统中，最常用且高效的文件拆分工具是 `split`，而合并文件则使用 `cat` 命令。 

------

### 1. 拆分文件 (`split`)

`split` 命令支持按照**文件大小**或**行数**来切分大文件。 

### 📌 按文件大小拆分（通用）

适用于压缩包、视频、镜像等任意类型的文件： 

```bash
split -b 10M large_file.zip part_
```

请谨慎使用此类代码。



- `-b 10M`：设置每个切片文件的大小为 10MB（支持 `K`, `M`, `G`）。 
- `large_file.zip`：需要拆分的目标大文件。 
- `part_`：生成的切片文件名前缀，系统会自动在后面追加字母后缀（如 `part_aa`, `part_ab`）。 

### 📌 按行数拆分（文本专用）

适用于日志文件、CSV、TXT 等文本文件： 

```bash
split -l 1000 large_text.txt part_
```

请谨慎使用此类代码。



- `-l 1000`：设置每个切片文件最多包含 1000 行。 

------

### 2. 合并文件 (`cat`)

合并时，利用 `cat` 命令配合通配符，按照字母或数字顺序将切片拼回原文件。 

### 📌 合并命令

```bash
cat part_* > merged_file.zip
```

请谨慎使用此类代码。



- `part_*`：匹配当前目录下所有以 `part_` 开头的切片文件。 
- `>`：重定向输出符，将所有切片内容按顺序写入新文件。 
- `merged_file.zip`：合并后生成的完整文件名。 

------

### 💡 实用进阶技巧

### 1. 使用数字后缀

默认生成的后缀是字母（如 `aa`, `ab`）。如果你更习惯使用数字后缀（如 `00`, `01`），可以加上 `-d` 参数，并用 `-a` 指定数字位数： 

```bash
split -b 10M -d -a 2 large_file.zip part_
```

请谨慎使用此类代码。



*生成的文件名为：`part_00`, `part_01`, `part_02`...* 

### 2. 校验文件完整性

为了确保合并后的文件没有损坏，建议在拆分前和合并后分别计算 MD5 值进行对比： 

```bash
# 拆分前记录 MD5
md5sum large_file.zip

# 合并后验证 MD5
md5sum merged_file.zip
```

请谨慎使用此类代码。



*如果两个 MD5 字符串完全一致，说明拆分与合并过程无损。*
