## k8s 修改节点数量上限

1、 查看节点默认上限

```bash
$ k describe node | grep pods
  pods:               110
  pods:               110
```

2、修改kubelet 参数并重启

```bash
$ vim /var/lib/kubelet/config.yaml
...
maxPods: 200
...
$ systemctl restart kubelet 
```

3、 验证kubelet 配置

```basgh
k describe node | grep pods
  pods:               110
  pods:               110
```

参考：[https://kubernetes.io/docs/reference/config-api/kubelet-config.v1beta1/](https://kubernetes.io/docs/reference/config-api/kubelet-config.v1beta1/)
